ABOUT THE SOCIETY

Built by students, for builders.

Code Craft bridges the gap between what's taught in class and what it actually takes to ship software. Every event we run is open to all MAJU students.

🎯
Open Access
Every event listing, speaker deck, and registration form is public. No gated accounts for university attendees.
🏆
Practical Sprints
We care about working code, real commits, live demos, and prototypes you can actually deploy — not slide decks.
🚀
Leadership Track
Members run real logistics, creative design, public awareness, and budget decisions — not just attend events.
